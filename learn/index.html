The workshop

Learn to code

Two games that teach you Python by giving you a job to do. Write a few lines, watch them work, and pick up real coding skills one shift at a time.

# your first line of Python print("Morning, chef") print("Car's on the ramp")

How it works

No setup, no experience needed

  1. Read the job

    Chef or Les tells you what's needed, and a short manual shows you the one new idea.

  2. Write a few lines

    Type real Python on your phone, with a key bar for the fiddly symbols.

  3. Run it and see

    Get it right and the job's signed off. Get it wrong and you get a plain-English hint, not a telling-off.

Python Kitchen

Chef Dorran shoutsRight, new starter! Tickets are coming in. Write the code, clear the rail!

Learn real Python by working the pass. Chef calls the orders, you write the code, and you climb the brigade from Kitchen Porter to Head Chef.

  • 24 tickets over four services, from print() to functions, dictionaries and try/except, then a graduation project where you build a real till
  • Real Python 3 running in your browser, checked against real output
  • Hints instead of answers, and error messages in plain English
  • A practice station to mess about in, plus a full Python cookbook with runnable examples

Garage Code

Les the foreman saysEvery car in here is broken. Read the error, find the fault, sign off the job!

The sequel to Python Kitchen. Every car that rolls into the bay has a broken program, and it's your job to fix it: read real error messages, hunt down bugs that don't crash, and get the whole fleet through MOT day.

  • 20 jobs across four bays, from reading your first error to classes, files and sorting
  • Real Python 3, so you learn to read the same error messages real programmers see
  • Les explains every error in plain English, and gives hints for £5 out of the till
  • Make your own broken jobs and send them to a mate with a share code
