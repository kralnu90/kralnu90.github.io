The workshop

Learn to code

Two games that teach you Python by giving you a job to do. Write a few lines, watch them work, and pick up real coding skills one shift at a time.

# your first line of Python print("Morning, chef") print("Car's on the ramp")

How it works

No setup, no experience needed

  1. Read the job

    Chef or Les tells you what's needed, and a short manual shows you the one new idea.

  2. Write a few lines

    Type real Python on your phone, with a key bar for the fiddly symbols.

  3. Run it and see

    Get it right and the job's signed off. Get it wrong and you get a plain-English hint, not a telling-off.

Which one first?

Either works. Here's the difference.

Garage Code

Shorter and gentler. Ten jobs with a manual page before each new idea, and a car that reacts to every line you write.

Jobs
10, from print() to functions
Extras
Make and share your own jobs
Pick this if you've never written a line of code.

Python Kitchen

Longer and deeper. Twenty-four tickets across four services, running real Python 3 in your browser.

Tickets
24, up to dictionaries and try/except
Extras
Practice station and a full cookbook
Pick this to go further, or after Garage Code.

Python Kitchen

Chef Dorran shoutsRight, new starter! Tickets are coming in. Write the code, clear the rail!

Learn real Python by working the pass. Chef calls the orders, you write the code, and you climb the brigade from Kitchen Porter to Head Chef.

  • 24 tickets over four services, from print() to functions, dictionaries and try/except
  • Real Python 3 running in your browser, checked against real output
  • Hints instead of answers, and error messages in plain English
  • A practice station to mess about in, plus a full Python cookbook with runnable examples

Learn to code · Garage sim

Garage Code

Les the foreman saysNothing goes up on my ramp without paperwork. Write the code, sign off the job!

Learn Python by running a car garage. Every job in the bay is a coding problem: book cars in, check tyres across a taxi fleet, read fault codes and pass MOT day.

  • 10 jobs from print() to functions, each with a short workshop manual page
  • The car reacts to your code: your reg goes on the plate, errors make the bonnet smoke
  • Hidden test cars, plain-English errors, and hints from Les for £5 out of the till
  • Make your own jobs and send them to a mate with a share code
